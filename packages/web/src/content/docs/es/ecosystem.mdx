Una colección de proyectos comunitarios construidos en OpenLegion.

:::note
¿Quieres agregar tu proyecto relacionado con OpenLegion a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-openlegion](https://github.com/awesome-openlegion/awesome-openlegion) y [openlegion.cafe](https://openlegion.cafe), una comunidad que agrega el ecosistema y la comunidad.
