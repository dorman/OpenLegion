# Documentation screenshots

Product screenshots live in this directory and are referenced from the root [README](../../README.md).

## Refreshing screenshots

When the Sandboxes UI, inspect dialog, or desktop VM display changes materially, capture new PNGs and replace:

| File | What to capture |
| --- | --- |
| `containers-page.png` | Desktop app → **Sandboxes** with at least one workload listed |
| `desktop-vm-display.png` | **Inspect** dialog → **Desktop** tab showing a running Linux desktop VM |

Use a consistent window size (1440×900 or similar) and the default dark desktop chrome. Commit updated images with the UI change that prompted the refresh.
